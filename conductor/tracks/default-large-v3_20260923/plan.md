## Overview

Flip `_DEFAULTS["model"]` in the faster-whisper backend from `base` to `large-v3`, update the one
test that pins the default, and bring `docs/backends/faster-whisper.md` in line, with a note on the
CPU and small-GPU cost. Tests that pass `model="tiny"` are left untouched.

Note: the conformance suite (`tests/test_conformance.py`) builds each backend with `{}` plus a few
extra configs, none of which set `model`. After this change those four configurations load
`large-v3` instead of `base`, so `pytest -k conformance` downloads 3.1 GB on first run and is
slower, especially on CPU. This plan leaves the suite as is, so it keeps testing the real default.

## Overview

Split the `Dockerfile` into a shared base stage and two targets, `gpu` and `cpu`, with `cpu` last
so a plain build is unchanged. The `gpu` target adds the `diarization` extra and the CUDA 12
wheels ctranslate2 needs beside torch's own CUDA libraries. Compose gains an opt-in `api-gpu`
service under the `gpu` profile with the NVIDIA device reservation. No Python code, backend
interface, transcript schema or manifest change is expected; if one turns out to be needed, stop
and ask.

Smoke runs use local models only. ElevenLabs is never called.
